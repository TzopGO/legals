# 2. ¿QUÉ DATOS PERSONALES RECABAMOS?

TzopGo recabará únicamente los datos personales que resulten necesarios, adecuados y relevantes para las finalidades informadas en este Aviso de Privacidad.

Los datos tratados dependerán del tipo de usuario y de las funcionalidades utilizadas.

## 2.1. Datos de usuarios o clientes

TzopGo podrá tratar las siguientes categorías de datos:

### a) Datos de identificación y autenticación

* Nombre asociado a la cuenta.
* Correo electrónico.
* Identificadores de cuenta generados por la Plataforma.
* Información necesaria para autenticar el acceso mediante servicios de terceros, cuando el usuario elija utilizar dichos mecanismos.

### b) Datos relacionados con pedidos

* Información relacionada con los pedidos realizados.
* Productos o artículos solicitados.
* Comercios involucrados.
* Información necesaria para la preparación y entrega del pedido.
* Historial de pedidos.
* Información relacionada con incidencias, aclaraciones o reclamaciones.

### c) Datos de ubicación

Cuando el usuario utilice la funcionalidad correspondiente, podrá proporcionar una ubicación mediante la selección de un punto dentro del mapa de la Plataforma.

Estos datos serán utilizados para identificar el punto de recogida, entrega o destino necesario para la realización del pedido.

**TzopGo no realizará un rastreo continuo de la ubicación del usuario por el solo hecho de utilizar la Plataforma.**

### d) Datos de contacto y comunicación

Podrán tratarse los datos que el usuario proporcione voluntariamente durante las comunicaciones necesarias para la operación del servicio, incluyendo información intercambiada con TzopGo, comercios y repartidores.

# 3. DATOS PERSONALES DE REPARTIDORES

Cuando una persona se registre o utilice la Plataforma como repartidor, TzopGo podrá tratar las siguientes categorías de datos personales, según los requisitos aplicables al servicio:

### a) Datos de identificación

* Nombre.
* Datos contenidos en documentos oficiales de identificación que resulten necesarios para verificar la identidad.
* Imagen o copia del documento proporcionado para dicha verificación, cuando corresponda.

### b) Datos relacionados con la actividad del repartidor

* Información de la cuenta.
* Historial de servicios realizados mediante la Plataforma.
* Información relacionada con pedidos aceptados y realizados.
* Información necesaria para la operación, soporte, seguridad y atención de incidencias.

### c) Datos relacionados con el vehículo

* Tipo de vehículo.
* Marca, cuando corresponda.
* Modelo.
* Color.
* Placa o matrícula, cuando sea requerida.
* Demás características necesarias para identificar el vehículo utilizado para realizar entregas.

### d) Documentación necesaria para la operación

Cuando resulte necesario conforme a la legislación aplicable o a las condiciones de operación de la Plataforma, TzopGo podrá recabar documentación relacionada con la identificación y habilitación del repartidor para realizar la actividad correspondiente, como licencia de conducir u otros documentos aplicables.

TzopGo limitará la recopilación de dicha información a aquella que resulte necesaria para las finalidades informadas.

# 4. DATOS PERSONALES SENSIBLES

TzopGo no solicitará deliberadamente datos personales sensibles para la operación ordinaria de la Plataforma, salvo que exista una finalidad legítima, concreta y acorde con sus actividades y que su tratamiento resulte jurídicamente procedente.

Los datos personales sensibles se encuentran sujetos a las reglas especiales previstas por la legislación aplicable.

TzopGo no utilizará datos personales sensibles para finalidades distintas de aquellas para las cuales, en su caso, hayan sido legítimamente recabados y autorizados.

Cuando un documento proporcionado por una persona contenga incidentalmente información que pueda constituir un dato personal sensible y dicha información no sea necesaria para la finalidad correspondiente, TzopGo procurará limitar su tratamiento a lo estrictamente necesario y adoptará las medidas aplicables para su protección.

# 7. BASES Y CONDICIONES DEL TRATAMIENTO

TzopGo tratará los datos personales de conformidad con la legislación aplicable.

El tratamiento podrá realizarse, según corresponda, cuando:

* La persona titular haya otorgado su consentimiento.
* Sea necesario para cumplir obligaciones derivadas de una relación jurídica entre la persona titular y TzopGo.
* Sea necesario para prestar un servicio solicitado por la persona titular.
* Exista una disposición jurídica que permita o exija el tratamiento.
* Sea necesario para el ejercicio o defensa de derechos.
* Se actualice alguno de los demás supuestos previstos por la legislación aplicable.

TzopGo no utilizará los datos personales para finalidades incompatibles con aquellas informadas en este Aviso de Privacidad.

Si TzopGo pretende realizar un tratamiento para una finalidad distinta a las establecidas en este Aviso, se observarán las obligaciones legales correspondientes, incluyendo, cuando resulte necesario, la obtención de un nuevo consentimiento.

# 13. CONSERVACIÓN, BLOQUEO Y SUPRESIÓN

TzopGo conservará los datos personales durante el tiempo que resulte necesario para cumplir las finalidades informadas y las obligaciones legales aplicables.

Cuando los datos personales dejen de ser necesarios para las finalidades que motivaron su tratamiento, TzopGo procederá a su supresión previo bloqueo, cuando corresponda, de conformidad con la legislación aplicable.

La eliminación de una cuenta no necesariamente implica la eliminación inmediata de todos los registros asociados cuando exista una obligación legal, contractual o causa legítima que justifique su conservación.

# 19. MEDIDAS DE SEGURIDAD

TzopGo implementará y mantendrá medidas de seguridad administrativas, técnicas y físicas destinadas a proteger los datos personales contra:

* Daño.
* Pérdida.
* Alteración.
* Destrucción.
* Uso no autorizado.
* Acceso no autorizado.
* Tratamiento no autorizado.

Las medidas de seguridad serán determinadas considerando, entre otros factores:

* La naturaleza de los datos personales.
* La sensibilidad de la información.
* Las finalidades del tratamiento.
* Los riesgos existentes.
* Las posibles consecuencias para las personas titulares.
* El desarrollo tecnológico.
* Las medidas de seguridad que TzopGo utilice para proteger su propia información.

TzopGo establecerá controles de acceso y mecanismos de confidencialidad para las personas que intervengan en cualquier fase del tratamiento.

La obligación de confidencialidad subsistirá aun después de terminada la relación con TzopGo.
